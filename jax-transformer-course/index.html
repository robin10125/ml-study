A Transformer in JAX, from zero

A rigorous course for people who know PyTorch or TensorFlow and zero JAX. By the end you will think natively in pure functions, pytrees, and PRNG keys — and you will define and train a working transformer language model in JAX, from an empty file, without reference.

How this course works

Each chapter is a short textbook — explanations with worked code — followed by a problem set. The problems are where the course actually happens: you write real JAX in the box (it saves automatically) and in a live Python session beside the page (pip install jax is the entire setup). The mechanics:

  • Write before you look. Every problem has a code workspace, progressive hints, and a reference solution that stays locked until you've made a genuine attempt. A 📖 Review link jumps to the section the problem draws on, for when you need to re-read.
  • Run your code. Most problems say "predict, then verify" or end with a concrete test (a shape, a number, an assertion). The REPL is the grader — use it before comparing with the reference.
  • Check the box only for problems you solved before opening the reference. Progress is stored locally per chapter and aggregated below; come back to unsolved problems a day later, then after three days.

Your progress

The route

Part I — JAX itself (no transformer in sight; PyTorch/TF contrasts throughout):

Ch 1 — Thinking in JAX. The design inversion: state as explicit data, not object internals. Immutable arrays and .at[], the purity contract and how impure code silently lies, PRNG keys and the splitting discipline.

Ch 2 — grad. Differentiation as a function transformation. value_and_grad, has_aux, argnums, stop_gradient, what replaces backward()/zero_grad() (and why nothing has to), and what grad actually builds.

Ch 3 — jit & vmap. Tracing: the one mechanism behind every JAX surprise. Shape-keyed compilation, control flow on traced values, the closure-capture trap, and vmap — write per-example code, batch it mechanically, get per-example gradients free.

Ch 4 — Pytrees. Parameters without modules: nested dicts, tree.map, init functions with fan-in scaling, optimizers as three lines, the canonical jitted train step, lax.scan — capped by a complete MLP pipeline you write closed-book.

Part II — the transformer:

Ch 5 — The Transformer on Paper. Embeddings, attention from first principles (with the \(\sqrt{d_h}\) variance argument), the causal mask and why it goes before softmax, multi-head as a free reshape, pre-LN residual blocks, weight tying, and the \(\ln V\) ritual.

Ch 6 — The Transformer in JAX. Chapter 5's diagram as ~80 lines: layer_norm, attention, mlp, block, forward, loss_fn, init_params — each one a problem in the implementation set, each one machine-verified in the companion code.

Ch 7 — Training, Sampling & Debugging. Adam from its equations (with the bias-correction proof), the jitted train step, the data pipeline, temperature sampling, the verified training run that memorizes Alice in Wonderland, and a debugging checklist keyed to the chapters.

Companion code

In code/, both machine-verified on this machine:

  • transformer.py — the reference single-file model (~200 lines, pure jax.numpy; no Flax, no Optax). The default run trains a 632 K-parameter character-level LM that fits its corpus (final loss 0.093 vs untrained baseline \(\ln 46 = 3.83\)) and prints a PASS line; expected output is embedded in Chapter 7.
  • test_jax_core.py — seven deterministic checks tying the code to the chapters: LayerNorm statistics, attention vs a per-head manual loop, the causality test, a hand-computed cross-entropy, the \(\ln V\) init loss, jax.grad vs finite differences, and Adam's first-step property. Expect ALL 7 CHECKS PASS.

Setup: python3 -m venv .venv && .venv/bin/pip install jax, then .venv/bin/python code/test_jax_core.py.

Prerequisites

Working PyTorch or TensorFlow experience (you've trained models and know what a loss, an optimizer, and an embedding are), NumPy fluency, and comfort with basic probability and gradients. No JAX whatsoever — Chapter 1 assumes none. If you want the architecture extensions afterward (RoPE, grouped-query attention, Mixture-of-Experts), the single-page advanced lesson ../transformer-jax.html picks up where Chapter 7 ends.
